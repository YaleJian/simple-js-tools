# simple-js-tools

一个保持小而清晰的 JavaScript 工具库。

```bash
npm install simple-js-tools
```

```js
import sTools from 'simple-js-tools'

sTools.compare.isNumber('12.5')
```

浏览器全局版本：

```html
<script src="https://unpkg.com/simple-js-tools/dist/simple-js-tools.js"></script>
```
